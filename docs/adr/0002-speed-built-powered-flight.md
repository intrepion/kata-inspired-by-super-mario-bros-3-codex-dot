Accepted through user-delegated recommended defaults.

Keep the deterministic public simulation and existing run speed, then distinguish walking from a held Run action. Add one explicit one-way cloud landing in Glass Orchard. Rehome existing optional pickup IDs instead of adding another reward counter; leave the safe lower route and all exit conditions intact. Follow high ascent vertically so the player remains visible. Preserve the established meta-progress schema and all saved completion/reward records. The cost is authored approximate physics and a single flight reward route rather than original shell/block/world-map breadth.
